# (仮称)タイムラインSNS

X(旧Twitter)風の、投稿・タイムライン・コメント・いいね・フォローができる学習目的のSNS
Webアプリケーション。受講生・個人など複数の利用者が使うことを想定し、いいね・コメントは
投稿者本人だけでなく第三者からも行える設計としている(詳細は[要件定義書](要件定義書.md)参照)。

現在、F-01(新規登録)・F-02(ログイン)・F-03(ログアウト)のバックエンド、および
新規登録・ログイン画面のフロントエンドを実装済み。その他機能・AWSデプロイは次フェーズ以降で進める。

### X/Twitterとの差別化ポイント

- インプレッション数(閲覧数)は表示しない
- リツイート(拡散)機能は用意しない
- その代わり、フォロー機能により「全体」「フォロー中」の2種類のタイムラインを持つ

## データモデル概要

詳細・ER図は[データベース設計書](docs/データベース設計書.md)を参照。

- `users`: 利用者(ユーザー名・メールアドレス・パスワード・自己紹介)
- `posts`: 投稿(本文・画像URL(任意))
- `comments`: 投稿へのコメント
- `likes`: 投稿へのいいね(利用者×投稿でUNIQUE)
- `follows`: 利用者間のフォロー関係(自己参照の多対多)

いいね数・コメント数は`posts`にカウンタを持たず、`likes`/`comments`をその都度`COUNT`集計して
算出する方針としている。

## プロトタイプMock

技術スタックを決定する前に、要件定義書・機能一覧・画面設計書の内容(F-01〜F-15、S-01〜S-06)を
一通り操作して確認できる、HTML/CSS/JavaScriptのみの静的プロトタイプを用意している
(サーバー・データベースは使用せず、`mock/script.js`内のJavaScriptオブジェクトを疑似データベースとして
`localStorage`に保存しているだけの簡易実装)。

```bash
cd mock
python3 -m http.server 8899
# ブラウザで http://localhost:8899 を開く
```

デモ用アカウント(いずれもパスワード: `password`): `tanaka@example.com` / `sato@example.com` /
`suzuki@example.com` / `yamada@example.com`

## バックエンド(会員登録・ログイン・ログアウト)

Java(Spring Boot) + MyBatis + SQLite + JWT認証(アクセストークン+リフレッシュトークン方式)で
実装している。詳細は
[技術スタック](docs/技術スタック.md)・[ローカル開発環境セットアップ](docs/ローカル開発環境セットアップ.md)を参照。

```bash
cd backend
mvn spring-boot:run
# http://localhost:8080/api/auth/register 等にPOSTして動作確認できる
```

エンドポイント: `POST /api/auth/register`・`POST /api/auth/login`・`POST /api/auth/refresh`・
`POST /api/auth/logout`・`GET /api/auth/me`(認証必須)。アクセストークンは短命(15分)、
リフレッシュトークンは長命(7日)で、`/api/auth/refresh`を呼ぶたびにリフレッシュトークンも
ローテーションされる。ログアウト・リフレッシュで使用済みになったトークンはjti(トークンID)を
blacklistに登録することで、以降使えなくする。

## フロントエンド(新規登録・ログイン画面)

Vue.js(Vite)で実装している。ログイン・新規登録に成功するとアクセストークン・リフレッシュ
トークン・ユーザー情報を`localStorage`に保存し、「ログイン成功」と表示するだけのプレースホルダー
画面(`/welcome`)に遷移する(タイムライン等の本実装は次フェーズ)。

```bash
cd frontend
npm install
npm run dev
# http://localhost:5173 を開く(/apiは自動的にバックエンド(8080)へプロキシされる)
```
