# (仮称)タイムラインSNS

X(旧Twitter)風の、投稿・タイムライン・コメント・いいね・フォローができる学習目的のSNS
Webアプリケーション(詳細は[要件定義書](要件定義書.md)参照)。

現時点では要件定義フェーズのドキュメント一式のみを作成しており、技術スタックの選定・実装・
AWSデプロイは次フェーズ以降で進める。

## ドキュメント

| ドキュメント | 内容 |
|---|---|
| [要件定義書](要件定義書.md) | 背景・目的・検収基準など全体の合意事項 |
| [機能一覧](docs/機能一覧.md) | 機能要件とスコープ外項目 |
| [画面設計書](docs/画面設計書.md) | 画面一覧・画面構成要素・画面遷移 |
| [データベース設計書](docs/データベース設計書.md) | ER図・テーブル定義・集計方針 |

## 主な機能(予定)

- 会員登録・ログイン・ログアウト
- 投稿(テキスト+画像、編集・削除)
- タイムライン(全体 / フォロー中の切り替え)
- コメント(投稿・一覧・件数表示)
- いいね(登録・解除・件数表示)
- ユーザー検索・フォロー/フォロー解除
- プロフィール画面(投稿一覧・フォロー数/フォロワー数)

X/Twitterとの差別化点として、インプレッション数の表示・リツイート機能は持たない
(詳細は[要件定義書](要件定義書.md)参照)。
