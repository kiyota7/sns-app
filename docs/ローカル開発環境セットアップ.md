# ローカル開発環境セットアップ

タスクボードプロジェクトと同じマシンで、Homebrewを使わずsudo不要な方法でJava/Mavenを
用意している(既に導入済みの場合はこの節は不要)。

## 導入済みのバージョン

| ツール | バージョン | 導入方法 |
|---|---|---|
| Java | Eclipse Temurin JDK 21 | tar.gz を `~/dev-tools/` に展開(インストーラ不要) |
| Maven | 3.9.9 | tar.gz を `~/dev-tools/` に展開(インストーラ不要) |

`~/.zshrc`にJAVA_HOME・PATHを追記済みであれば、新しいターミナルで`java` `mvn`コマンドが
そのまま使える。

## バックエンドアプリの起動

```bash
cd backend
mvn spring-boot:run
```

起動時に`schema.sql`が自動実行され、`backend/sns.db`(SQLite、Git管理外)にテーブルが
作成される。初回起動後、`http://localhost:8080/api/auth/register`等にアクセスできる。

## 動作確認(curl)

```bash
# 新規登録(自動的にJWTが発行される)
curl -X POST http://localhost:8080/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"tanaka","email":"tanaka@example.com","password":"password123"}'

# ログイン
curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"tanaka@example.com","password":"password123"}'

# 認証確認(<TOKEN>は上記レスポンスのtoken)
curl http://localhost:8080/api/auth/me -H "Authorization: Bearer <TOKEN>"

# ログアウト(以降そのトークンは無効になる)
curl -X POST http://localhost:8080/api/auth/logout -H "Authorization: Bearer <TOKEN>"
```

## ポート番号

- バックエンド(Spring Boot, `backend/`): **8080**

フロントエンドは次フェーズで追加する。
