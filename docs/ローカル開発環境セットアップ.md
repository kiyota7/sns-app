# ローカル開発環境セットアップ

タスクボードプロジェクトと同じマシンで、Homebrewを使わずsudo不要な方法でJava/Mavenを
用意している(既に導入済みの場合はこの節は不要)。

## 導入済みのバージョン

| ツール | バージョン | 導入方法 |
|---|---|---|
| Java | Eclipse Temurin JDK 21 | tar.gz を `~/dev-tools/` に展開(インストーラ不要) |
| Maven | 3.9.9 | tar.gz を `~/dev-tools/` に展開(インストーラ不要) |

`~/.zshrc`にJAVA_HOME・PATHを追記済みであれば、新しいターミナルで`java` `mvn`コマンドが
そのまま使える。

## バックエンドアプリの起動

```bash
cd backend
mvn spring-boot:run
```

起動時に`schema.sql`が自動実行され、`backend/sns.db`(SQLite、Git管理外)にテーブルが
作成される。初回起動後、`http://localhost:8080/api/auth/register`等にアクセスできる。

## 動作確認(curl)

```bash
# 新規登録(アクセストークン・リフレッシュトークンが発行される)
curl -X POST http://localhost:8080/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"tanaka","email":"tanaka@example.com","password":"password123"}'

# ログイン
curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"tanaka@example.com","password":"password123"}'

# 認証確認(<ACCESS_TOKEN>は上記レスポンスのaccessToken)
curl http://localhost:8080/api/auth/me -H "Authorization: Bearer <ACCESS_TOKEN>"

# トークンのリフレッシュ(<REFRESH_TOKEN>は上記レスポンスのrefreshToken。使用済みのrefreshTokenは無効化される)
curl -X POST http://localhost:8080/api/auth/refresh \
  -H "Content-Type: application/json" \
  -d '{"refreshToken":"<REFRESH_TOKEN>"}'

# ログアウト(アクセストークン・リフレッシュトークンの両方が以降使えなくなる)
curl -X POST http://localhost:8080/api/auth/logout \
  -H "Authorization: Bearer <ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"refreshToken":"<REFRESH_TOKEN>"}'

# 投稿の作成(画像は任意。imageパートを省略すればテキストのみの投稿になる)
curl -X POST http://localhost:8080/api/posts \
  -H "Authorization: Bearer <ACCESS_TOKEN>" \
  -F "body=はじめての投稿です" \
  -F "image=@/path/to/image.png;type=image/png"

# タイムライン取得(全体、新しい順)
curl http://localhost:8080/api/posts -H "Authorization: Bearer <ACCESS_TOKEN>"

# 投稿の編集(本人のみ。他人の投稿を指定すると403)
curl -X PUT http://localhost:8080/api/posts/<POST_ID> \
  -H "Authorization: Bearer <ACCESS_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"body":"編集後の本文"}'

# 投稿の削除(本人のみ)
curl -X DELETE http://localhost:8080/api/posts/<POST_ID> -H "Authorization: Bearer <ACCESS_TOKEN>"
```

投稿画像は`backend/uploads/`(Git管理外)にローカル保存され、`http://localhost:8080/uploads/<ファイル名>`
で認証不要のまま取得できる。

## フロントエンドアプリの起動

```bash
cd frontend
npm install
npm run dev
```

`http://localhost:5173`を開く。Vite devサーバーの`server.proxy`設定により、`/api`宛のリクエストは
自動的に`http://localhost:8080`へプロキシされるため、CORS設定は不要。

## ポート番号

- バックエンド(Spring Boot, `backend/`): **8080**
- フロントエンド(Vite, `frontend/`): **5173**

ポートが競合していても、空いている別のポートに逃がさず、上記のポートで起動すること。
