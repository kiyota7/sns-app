# 画面設計書

タイムライン型SNSアプリの画面設計。
機能の詳細は [機能一覧.md](機能一覧.md) を参照。

## 画面一覧

本システムは以下の6画面で構成される。

| 画面ID | 画面名 | 概要 |
|---|---|---|
| S-01 | ログイン画面 | メールアドレス・パスワードを入力してログインする画面(未ログイン時の初期画面) |
| S-02 | 新規登録画面 | ユーザー名・メールアドレス・パスワードを入力して新規アカウントを作成する画面 |
| S-03 | タイムライン画面 | 「全体」「フォロー中」を切り替えられる投稿一覧のメイン画面(ログイン後の初期画面) |
| S-04 | 投稿詳細画面 | 1件の投稿本文と、それに対するコメント一覧・コメント投稿フォームを表示する画面 |
| S-05 | プロフィール画面 | 指定した利用者の基本情報・フォロー数/フォロワー数・投稿一覧を表示する画面 |
| S-06 | ユーザー検索画面 | ユーザー名で他の利用者を検索する画面 |

## 画面構成要素

### S-01 ログイン画面 / S-02 新規登録画面

- タイトル、入力欄(S-01: メールアドレス・パスワード / S-02: ユーザー名・メールアドレス・パスワード)、
  送信ボタン(「ログイン」/「登録する」)
- エラーメッセージ表示欄(認証失敗、ユーザー名・メールアドレス重複時)
- もう一方の画面への切り替えリンク

### S-03 タイムライン画面

- ヘッダー: アプリタイトル、ログイン中のユーザーアイコン/名前(押下でS-05へ)、検索アイコン(押下でS-06へ)、
  ログアウトボタン
- タブ: 「全体」「フォロー中」(F-07, F-08)
- 新規投稿フォーム: テキスト入力欄、画像添付ボタン、投稿ボタン(F-04)
- 投稿カード(一覧、複数): 投稿者名(押下でS-05へ)、投稿本文、添付画像(あれば)、投稿日時、
  いいねボタン+いいね数(F-11, F-12)、コメントアイコン+コメント数(押下でS-04へ、F-10)、
  自分の投稿の場合のみ編集・削除メニュー(F-05, F-06)

### S-04 投稿詳細画面

- 投稿本文(S-03と同じ表示要素)
- コメント一覧(投稿者名、コメント本文、投稿日時。新しい順)
- コメント投稿フォーム(テキスト入力欄、送信ボタン)
- 戻るボタン(S-03または直前の画面へ)

### S-05 プロフィール画面

- ユーザー名、自己紹介(任意)、フォロー数・フォロワー数
- 自分のプロフィールの場合: プロフィール編集ボタン
- 他人のプロフィールの場合: フォロー/フォロー解除ボタン(F-14)
- そのユーザーの投稿一覧(S-03の投稿カードと同じ表示要素)

### S-06 ユーザー検索画面

- ユーザー名検索入力欄
- 検索結果一覧(ユーザー名、フォロー/フォロー解除ボタン。行押下でS-05へ)

## 画面遷移

- 未ログイン時はS-01(ログイン画面)を表示する
- S-01とS-02は切り替えリンクで相互に遷移する
- S-01でログインに成功、またはS-02で新規登録に成功すると、S-03(タイムライン画面)に遷移する
- S-03のタブ切り替え(「全体」⇔「フォロー中」)では画面遷移せず、一覧内容のみ切り替わる
- S-03の投稿カードのコメントアイコンを押すとS-04(投稿詳細画面)に遷移する
- S-03・S-04・S-06の投稿者名/ユーザー名を押すとS-05(プロフィール画面)に遷移する
- S-03のヘッダーの検索アイコンを押すとS-06(ユーザー検索画面)に遷移する
- S-03のヘッダーの「ログアウト」を押すとS-01(ログイン画面)に戻る

```
S-01 ログイン ⇄ S-02 新規登録
        │(認証成功)
        ▼
S-03 タイムライン(全体/フォロー中) ── コメントアイコン ──▶ S-04 投稿詳細
        │  ▲                                                  │
    検索アイコン                                          投稿者名押下
        ▼  │                                                  │
S-06 ユーザー検索 ──────────── ユーザー名押下 ─────────▶ S-05 プロフィール
```

## 画面イメージ(ワイヤーフレーム)

### S-01 ログイン画面 / S-02 新規登録画面

```
        +------------------------------+
        |         (仮称)SNS            |
        +------------------------------+
        |  [ エラーメッセージ(任意) ]  |
        |  メールアドレス                |
        |  [__________________________] |
        |  パスワード                   |
        |  [__________________________] |
        |  [        ログイン          ] |
        |  アカウントをお持ちでない方は  |
        |  新規登録                      |
        +------------------------------+
```

### S-03 タイムライン画面

```
+----------------------------------------------------------------------+
|  (仮称)SNS        [検索🔍]           ○○さん(アイコン)  [ログアウト] |
+----------------------------------------------------------------------+
|  [ 全体 ] [ フォロー中 ]                                              |
+----------------------------------------------------------------------+
|  [ いまどうしてる?________________________ ] [画像添付] [投稿]        |
+----------------------------------------------------------------------+
|  △△さん  ・2026/07/30 10:00                                          |
|  今日は朝から勉強を頑張った。                                          |
|  [画像]                                                                |
|  ♡ 3    💬 2                                        (自分の投稿:編集/削除)|
|  ------------------------------------------------------------------  |
|  □□さん  ・2026/07/29 21:00                                          |
|  明日から新しい教材を始める予定。                                       |
|  ♡ 1    💬 0                                                          |
+----------------------------------------------------------------------+
```

### S-04 投稿詳細画面

```
+----------------------------------------------------------------------+
|  ← 戻る                                                               |
+----------------------------------------------------------------------+
|  △△さん  ・2026/07/30 10:00                                          |
|  今日は朝から勉強を頑張った。                                          |
|  [画像]                                                                |
|  ♡ 3    💬 2                                                          |
+----------------------------------------------------------------------+
|  [ コメントを入力__________________________ ] [送信]                  |
+----------------------------------------------------------------------+
|  □□さん  ・2026/07/30 10:15  えらい!                                 |
|  ▽▽さん  ・2026/07/30 10:30  私も頑張ろう                             |
+----------------------------------------------------------------------+
```

### S-05 プロフィール画面

```
+----------------------------------------------------------------------+
|  ← 戻る                                                               |
+----------------------------------------------------------------------+
|  (アイコン)  △△さん                                                  |
|  自己紹介文がここに表示される                                          |
|  フォロー中: 12   フォロワー: 8        [ フォローする / 解除する ]      |
+----------------------------------------------------------------------+
|  △△さんの投稿一覧(タイムラインと同じ表示形式)                        |
+----------------------------------------------------------------------+
```

### S-06 ユーザー検索画面

```
+----------------------------------------------------------------------+
|  ← 戻る                                                               |
|  [ ユーザー名で検索_______________________ ] [検索]                   |
+----------------------------------------------------------------------+
|  △△さん                                        [ フォローする ]       |
|  △△子さん                                       [ フォロー中 ]        |
+----------------------------------------------------------------------+
```

- 投稿カードの表示形式(投稿者名・本文・画像・いいね/コメント数)はS-03・S-04・S-05で共通とする
- 画像は任意添付のため、無い投稿では画像領域を表示しない
