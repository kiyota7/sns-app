# 技術スタック

タイムライン型SNSアプリの開発環境・使用技術。

現時点ではバックエンド(会員登録・ログイン・ログアウト・投稿の作成/編集/削除・タイムライン取得)と、
フロントエンドの新規登録・ログイン・タイムライン画面を実装している。

## バックエンド

| 分類 | 内容 | バージョン |
|---|---|---|
| 言語 | Java(Eclipse Temurin) | 21 |
| フレームワーク | Spring Boot | 3.5.0 |
| データアクセス | MyBatis(XMLマッパーで明示的にSQLを記述) | mybatis-spring-boot-starter 3.0.4 |
| 認証 | JWT(`io.jsonwebtoken`/jjwt)。アクセストークン(15分)+リフレッシュトークン(7日)方式で、Spring Securityをステートレス構成にし、独自の`JwtAuthenticationFilter`で`Authorization: Bearer <token>`ヘッダを検証する。リフレッシュ・ログアウト時にjti(トークンID)をblacklistへ登録して失効させる。パスワードはBCryptでハッシュ化 | jjwt 0.12.6 |
| ビルドツール | Maven | 3.9.9 |
| API方式 | REST(JSON。投稿作成のみ`multipart/form-data`) | - |
| ファイルアップロード | 投稿画像はS3等を使わずローカルディスク(`backend/uploads/`)に保存し、`/uploads/**`で静的配信 | Spring MVCの`MultipartFile`(追加ライブラリ不要) |

## フロントエンド

| 分類 | 内容 | バージョン |
|---|---|---|
| フレームワーク | Vue.js(Composition API, `<script setup>`) | 3.5.x |
| ビルドツール | Vite | 8.x |
| ルーティング | Vue Router | 5.x |
| 状態管理 | なし(この規模ではPinia等は使わず、認証情報は`localStorage`で管理) | - |
| 言語 | JavaScript(TypeScriptは不使用) | - |
| バックエンドとの通信 | Vite devサーバーの`server.proxy`で`/api`をバックエンド(`:8080`)へプロキシ(CORS対応不要) | - |

## データベース

| 分類 | 内容 |
|---|---|
| DBMS | SQLite(ファイルベース。`backend/sns.db`) |
| スキーマ管理 | `schema.sql`(Spring Bootの`spring.sql.init`により起動時に自動実行) |

## 前回までとの違い

タスクボード・家計簿とは異なる組み合わせを採用している。

| 分類 | タスクボード | 家計簿 | 今回(SNS) |
|---|---|---|---|
| バックエンド言語 | Java | Ruby | Java |
| データアクセス | Spring Data JPA(Hibernate) | Active Record | MyBatis |
| データベース | PostgreSQL | MySQL | SQLite |
| 認証方式 | セッション/Cookie | (未実装) | JWT(アクセス+リフレッシュトークン) |
| フロントエンド | React(Vite) | Next.js | Vue.js(Vite) |

言語はタスクボードと同じJavaだが、データアクセス層(Spring Data JPA → MyBatis)と
認証方式(セッション → JWT)をあえて変えることで、異なる実装パターンを学習する狙いがある。
フロントエンドもタスクボード(React)・家計簿(Next.js)のいずれとも異なるVue.jsを採用している。
