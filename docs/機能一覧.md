# 機能一覧

タイムライン型SNSアプリの機能要件一覧。
全体の背景・目的は [要件定義書.md](../要件定義書.md) を参照。

## 機能要件

本システムが備える機能は以下の通りとする。

| 機能ID | 機能名 | 概要 |
|---|---|---|
| F-01 | 新規登録 | ユーザー名・メールアドレス・パスワードを入力して新規登録すると、自動的にログインする。既に使われているユーザー名・メールアドレスでは登録できない |
| F-02 | ログイン | 登録済みのメールアドレス(またはユーザー名)・パスワードでログインする。誤っている場合はエラーを表示する |
| F-03 | ログアウト | ログイン状態を終了し、ログイン画面に戻る |
| F-04 | 投稿の作成 | テキスト(本文)を入力して投稿する。画像の添付は任意 |
| F-05 | 投稿の編集 | 自分の投稿の本文を編集できる(他人の投稿は編集できない) |
| F-06 | 投稿の削除 | 自分の投稿を削除できる(確認ダイアログあり。他人の投稿は削除できない)。削除すると紐づくコメント・いいねも削除される |
| F-07 | 全体タイムライン表示 | 全利用者の投稿を、新しい順に一覧表示する |
| F-08 | フォロー中タイムライン表示 | 自分がフォローしている利用者の投稿のみを、新しい順に一覧表示する。タイムライン画面で「全体」「フォロー中」をタブ切り替えできる(F-07と対になる) |
| F-09 | コメントの投稿 | 投稿詳細画面から、その投稿に対してコメント(テキスト)を投稿できる |
| F-10 | コメント一覧・件数の表示 | 投稿詳細画面でコメントを新しい順に一覧表示する。タイムライン上の各投稿にもコメント件数を表示する |
| F-11 | いいねの登録・解除 | 投稿に対して「いいね」ボタンを押すと登録され、もう一度押すと解除される(1利用者につき1投稿1回まで) |
| F-12 | いいね数の表示 | タイムライン・投稿詳細画面で、各投稿のいいね数を表示する |
| F-13 | ユーザー検索 | ユーザー名の部分一致検索で、他の利用者を検索できる |
| F-14 | フォロー・フォロー解除 | ユーザー検索結果やプロフィール画面から、他の利用者をフォロー・フォロー解除できる(自分自身はフォローできない) |
| F-15 | プロフィール画面表示 | 指定した利用者の基本情報(ユーザー名等)・フォロー数/フォロワー数・その利用者の投稿一覧を表示する。自分のプロフィールの場合は編集導線を、他人のプロフィールの場合はフォロー/フォロー解除ボタンを表示する |

F-07・F-08(タイムライン)、F-09〜F-12(コメント・いいね)は、どの投稿からも同じ挙動で
利用できる(自分の投稿・他人の投稿を問わない)。

## 機能対象外(スコープ外)とする項目

学校課題として簡易実装とするため、以下の機能は本システムの対象外とする。

- インプレッション数(閲覧数)の表示
- リツイート(拡散)機能
- ダイレクトメッセージ(利用者間の非公開メッセージ)
- 通知機能(いいね・コメント・フォローされた際の通知)
- ハッシュタグ・キーワードによる投稿本文の検索(ユーザー検索のみ対応)
- パスワード再設定機能
- 非公開アカウント(フォロー承認制)
